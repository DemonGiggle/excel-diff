# Privacy policy

Excel Compare is an offline desktop application. It does not collect telemetry,
analytics, crash reports, personal information, or workbook contents.

This program will not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it.

The application reads only the workbook files selected by the user. It opens
those files read-only and does not upload them or modify them. The application
does not make network requests. Its open-source third-party components operate
locally and do not introduce separate data collection or network services.

The operating system and the software-distribution service used to obtain the
application may have their own privacy policies. Those services are outside the
application and are not controlled by this project.

Questions about this policy can be raised through the project's GitHub issue
tracker: https://github.com/DemonGiggle/excel-diff/issues
